Automatically inserts structured data (JSON-LD) into WordPress sites and allows one-click application of improvement suggestions from Action Engine (GPT).

== Description ==

WP Booster Lite helps your WordPress site get noticed by AI search engines by automatically adding structured data (JSON-LD). It also seamlessly integrates with Action Engine (GPT) to apply SEO and content improvement suggestions with a single click.

Key Features:
* Automatic JSON-LD generation for various schema types (Article, FAQ, HowTo, Product, etc.).
* One-click application of AI-powered improvement suggestions.
* Easy to use and configure.

== Installation ==

1. Upload the `wp-booster-lite` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure the plugin settings under 'Settings > WP Booster Lite' (actual menu item may vary).

== Frequently Asked Questions ==

= What types of structured data does it support? =
Currently, the plugin supports Article, FAQ, HowTo, and Product schema. More will be added in future versions.

= How does the Action Engine integration work? =
The plugin provides an endpoint for the Action Engine (GPT) to send suggestions. These suggestions will appear in your WordPress admin area, where you can review and apply them with one click.
